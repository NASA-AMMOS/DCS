# Data Cryptography Services (DCS) Space Data Link Security (SDLS) Python Client Interface

SDLS SDLS supports the following functionality:

- Apply Security to Telecommand Transfer (TC) Frames
- Reverse Security from Telecommand Transfer (TC) Frames
- Apply Security to Telemetry (TM) Frames
- Reverse Security from Telemetry (TM) frames
- Apply Security to Advanced Orbiting Systems (AOS) Frames
- Reverse Security from Advanced Orbiting Systems (AOS) Frames

Interface specifications are available in the DCS 4.0 Software Interface Specification (SIS) document.
